# 1026 풀이방법 및 트러블슈팅

---

### 문제
옛날 옛적에 수학이 항상 큰 골칫거리였던 나라가 있었다. 

이 나라의 국왕 김지민은 다음과 같은 문제를 내고 큰 상금을 걸었다.

길이가 N인 정수 배열 A와 B가 있다. 다음과 같이 함수 S를 정의하자. 

S = A[0] × B[0] + ... + A[N-1] × B[N-1]

S의 값을 가장 작게 만들기 위해 A의 수를 재배열하자. 단, B에 있는 수는 재배열하면 안 된다.

S의 최솟값을 출력하는 프로그램을 작성하시오.

--- 

### 입력
첫째 줄에 N이 주어진다. 둘째 줄에는 A에 있는 N개의 수가 순서대로 주어지고, 

셋째 줄에는 B에 있는 수가 순서대로 주어진다. 

N은 50보다 작거나 같은 자연수이고, A와 B의 각 원소는 100보다 작거나 같은 음이 아닌 정수이다.

```bash
5
1 1 1 6 0
2 7 8 3 1
```

---

### 출력
첫째 줄에 S의 최솟값을 출력한다.

```bash
18
```

--- 

### 풀이 전략
이 문제는 두 배열의 각 요소를 곱한 값의 총합이 가장 작아지도록 배열 A를 재배열하는 문제입니다.

합을 최소화하기 위한 핵심은 한 배열의 가장 큰 값과 다른 배열의 가장 작은 값이 곱해지도록 하는 것입니다.

배열 A는 오름차순으로, 배열 B는 내림차순으로 정렬하여 양극단의 값이 서로 곱해지도록 했습니다.

B에 있는 수는 재배열하면 안 된다는 조건에 맞춰 배열 A가 실제로 어떻게 재배열되어야 하는지 구현했습니다. 

이를 위해 원본 배열을 복제한 후, 배열 B의 원래 인덱스 위치를 2차원 배열 형태로 함께 저장하여 

계산이 끝난 후 배열 A를 원본 B의 순서에 맞게 재배치하는 방식을 풀이하였습니다.

---

### 풀이 과정

1. 두 배열 A, B를 복제하였고 B에 원본의 요소에 대한 인덱스 위치 값을 함께 저장하였습니다.

2. 이후 복제한 A를 오름차순, 복제한 B를 내림차순 정렬합니다.

3. 인데스 값이 동일한 각각의 요소를 곱하고 cp_arr_A에 곱한 배열 B 요소의 인덱스 값을 2차원 배열 형태로 같이 저장합니다.

4. cp_arr_A에 저장된 인덱스 값을 통해 재정렬합니다.


### 시간 복잡도

- O(n log n)
